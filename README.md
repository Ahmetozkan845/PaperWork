# 📘 PaperWork.Api

### 🧩 İsterler

---

#### 🔹 API Gereksinimleri

REST mimarisiyle çalışacak şekilde tasarlanmalıdır ve aşağıdaki işlemleri desteklemelidir:

- **INSERT** – Yeni kayıt ekleme  
- **UPDATE** – PWId üzerinden kayıt güncelleme  
- **SELECT** – Kayıtları listeleme (isteğe bağlı olarak PWId üzerinden filtreleme)

---

### ⚙️ Yapılandırma

Projede yer alan **`appsettings.json`** dosyasındaki **sunucu adresi alanı**,  
uygulama dağıtıldığı ortamın adresine göre **güncellenmelidir.**
